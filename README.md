# Arishi Gupta - Portfolio Website

A modern, responsive portfolio website showcasing my skills, experience, and projects as a full-stack software developer.

## 🌟 Features

- **Hero Section**: Engaging introduction with call-to-action buttons and statistics
- **Skills & Technologies**: Interactive tech stack display with 34+ technologies using devicons
- **Professional Experience**: Timeline view of work experience with detailed project descriptions
- **Featured Projects**: Showcase of key projects with achievements and tech stack
- **Education & Publications**: Academic background and research publications
- **Dark/Light Mode**: Theme toggle for user preference
- **Responsive Design**: Fully responsive layout optimized for all devices
- **Smooth Animations**: CSS animations and transitions for engaging UX

## 🚀 Tech Stack

- **Frontend**: React 18
- **Build Tool**: Vite
- **Styling**: CSS3 with CSS Variables
- **Package Manager**: npm
